Notepad Hacker Edition

This Notepad project is a Python-based text editor styled to look like a hacker’s terminal. It includes a modern black-and-green UI theme, keyboard shortcuts, auto-save features, and customizable fonts for an immersive “cyber” feel.

Key Features:

  • Custom black & neon-green hacker interface
  • Auto-save and quick load functionality
  • Keyboard shortcuts for fast editing
  • Written in Python with Tkinter
