## 🎯 Features

- **Hacker Aesthetic**: Cyberpunk-inspired design with green-on-black theme
- **Responsive Design**: Fully responsive across all devices
- **Project Showcase**: Detailed project pages with code examples
- **Interactive Elements**: Animated typing effects, scanning lines, and hover animations
- **Fast Loading**: Optimized performance with minimal dependencies
- **Cross-Browser Compatible**: Works on all modern browsers

## 🚀 Projects Featured

### 1. Human Typing Simulator
Python GUI application that simulates realistic human typing behavior with customizable speed and mistake rates.

### 2. Face Recognition Attendance System
Automated attendance system using OpenCV and facial recognition technology.

### 3. Alexa with Python
Voice assistant built with Python featuring speech recognition and text-to-speech.

### 4. Notepad Hacker Edition
Hacker-themed text editor with custom interface and advanced features.

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript
- **Styling**: Custom CSS with CSS Variables
- **Icons**: Font Awesome 6.4.0
- **Fonts**: JetBrains Mono, Poppins (Google Fonts)
- **Deployment**: GitHub Pages / Netlify
